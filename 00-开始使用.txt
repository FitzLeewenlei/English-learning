海纳英语微信小程序 · 全部 120 个 Unit

1. 解压，打开微信开发者工具并导入含 project.config.json 的整个文件夹。
2. 填入自己的 AppID，点击编译；前端不用构建 npm。
3. 全部 120 个 Unit、1800 词条和1800组例句已导入，单元资料按需加载。
4. Unit 1 录音内置，其余默认读取现有网站音频。完整4524个录音保存在 audio-resources/audio。
   按单元查看录音请打开 audio-by-unit/Unit001 至 Unit120，每单元有15个单词录音和15个例句录音及对照表。
5. 正式使用完整音频，建议按 README 第4节上传自己的云存储并填 audioCloudRoot。
6. 学生入班、教师工作台与同步需要按 README 第3节开通自己的云开发环境。
7. 用真实手机预览，再完成微信后台审核发布；压缩包不代替账号和审核。

README.md 是完整操作说明。QA_REPORT.md 记录本次实际检查结果。
旧版出现“单元加载失败”时，请把2.0.1新版解压到新目录重新导入，填回自己的AppID和云环境，在开发者工具清除全部缓存后重新编译。不要只复制页面文件。
