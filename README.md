# 海纳英语 · 微信小程序（完整 120 单元版）

这是当前英语点读网站的原生微信小程序移植工程，课程快照来自 https://fitzleewenlei.github.io/English-learning/ ，源码版本见 `SOURCE.json`。解压后直接导入包含 `project.config.json` 的工程根目录。

## 本次完整迁移内容

| 内容 | 数量与处理 |
|---|---|
| Unit 目录 | 1–120 全部开放 |
| 文档词条 | 1,800 条，原单词、音标、词性和中文释义保留 |
| 真题例句 | 1,800 组，保留英文、中文、出处及 530 处词形批注 |
| 有道词卡 | 3,905 个查询词形，保留音标、多词性释义、词头提示、来源及缺项 |
| 录音 | 4,524 个当前引用文件，原 MP3/WAV 原样保存在 `audio-resources/audio/`，约 135 MB |
| 字幕 | 1,800 组例句的既有词级时间数据，文字推进时不读中文批注和出处 |
| 背词 | 新词、到期复习、三档自评、听音拼写、账号学习进度 |
| 师生框架 | 学生入班、教师邀请验证、班级学习详情、班级通知及已读 |

词书展示始终保留 1,800 条记录。单词、音标、词性和释义四项完全相同的重复记录共用一张记忆卡，因此背词系统共 1,783 张卡；不同词性或释义保留独立卡。例句和词卡均来自网站已有资料，没有另行编写学习内容。词书音标取文档原文，有道词卡缺音标时明确显示“有道音标暂缺”，不拿文档音标或原形发音替代。

## 1. 直接导入开发者工具

1. 解压工程，打开微信开发者工具的小程序“导入项目”。
2. 选择本 README 所在目录，不能只选里面的 `miniprogram`。
3. 填入自己的真实 AppID；只看模拟器可用工具支持的测试/游客模式。前端无需构建 npm。
4. 点击编译，进入“词书点读”。Unit 1–120 的完整资料均在资源分包中，第一次切换会加载对应分包，之后复用缓存。
5. 当前 Unit 1 的 144 个相关录音已内置在 3 个音频分包中。其余单元默认从现有网站按需读取音频，便于预览。原站可用性和小程序正式域名要求仍需核对；正式使用建议按第 4 节切到自己的云存储。
6. 可测试词书、句中词卡、例句来源、单词依次朗读、字幕播放器、背词及听写。

小程序主包约 0.56 MB，8 个单元资料分包和 3 个演示录音分包均低于 2 MiB，总包约 15.1 MB。完整录音备份及来源审计在 `miniprogramRoot` 之外，不会被塞进微信代码包。

## 2. 正式发布的账号配置

工程保留游客 AppID，不能代替运营者的小程序账号。请在开发者工具里填真实 AppID，或修改 `project.config.json` 的 `appid`。AppID 不是 AppSecret，前端不应填写 AppSecret。

在微信后台按实际运营主体完成注册、备案、类目/资质、名称和图标配置；完善隐私保护指引及有效联系方式。学生端本机点读、背词可以先测试，真实师生服务需要下面的云开发配置。

## 3. 开通真实师生功能

### 3.1 初始化环境

1. 用真实 AppID 打开工程，在开发者工具的“云开发”里创建属于你的小程序的环境，复制环境 ID。
2. 修改 `miniprogram/config.js`，仅填写自己的环境 ID：

```js
cloudEnv: '你的云环境ID',
```

3. 在开发者工具中对 `cloudfunctions/learning` 右键，选择“上传并部署：云端安装依赖”。前端不用构建 npm，只有云函数需要安装它自己的 `wx-server-sdk`。
4. 在云函数控制台把该函数超时时间设为 60 秒；弱网补传采用每批最多 40 条记录。云函数环境和客户端环境必须属于同一条微信云开发链路，不要改接独立 CloudBase 自定义登录后混用两套身份。

### 3.2 指定首位管理员

1. 编译小程序，在“我的”中进入“学生 / 教师入口”。
2. 点击页底“复制我的账号编号”。这个编号由云函数根据当前微信身份生成；只能取得自己的编号。
3. 在 `learning` 云函数的**云端环境变量**添加 `ADMIN_ACCOUNT_IDS`，值填刚复制的编号。多名管理员用英文逗号分隔。不要在前端配置文件中写管理员名单。
4. 保存环境变量使云函数使用新配置，然后回到“我的”刷新或重新进入。管理员首次访问会创建所需数据库集合并显示“管理员账号”。
5. 已取消管理员资格时，从云端变量移除其编号即可，服务端不会仅依靠旧界面缓存授权。

### 3.3 数据库权限与索引

所有学习数据通过 `learning` 云函数读写。对下面 10 个集合，逐一进入数据库“数据权限 / 安全规则”，设置为：

```json
{"read":false,"write":false}
```

集合名是 `users`、`classes`、`classCodes`、`teacherInvites`、`studentClaims`、`progress`、`studyEvents`、`dailyStats`、`notices`、`readReceipts`。根目录 `database.rules.json` 是逐集合配置清单，**不是会自动生效的部署文件**。不要把整份清单粘贴进单个集合规则，也不要为了调试把学生记录设为公开可读写。服务端 SDK 仍可在云函数内按业务权限操作这些集合。

为后续数据增长建议创建以下非唯一索引，通知排序索引在正式发布前配置：

| 集合 | 索引字段（从左到右） |
|---|---|
| users | classId 升序，role 升序，status 升序 |
| progress | userId 升序 |
| dailyStats | classId 升序，day 升序，practiceCount 升序 |
| notices | classId 升序，published 升序，createdAt 降序 |

如微信控制台根据实际查询提示其他索引，按提示补建。用户标识、班级归属和教师权限均在云函数内重新验证，前端提交的 `userId` 或伪造的班级不能越权。

### 3.4 创建班级、老师和学生

1. 管理员进入“我的 / 教师工作台”，创建班级。系统生成班级码并复制到剪贴板。
2. 管理员在该班级下生成教师邀请码。邀请码只可使用一次，7 天后过期。班级码不能替代教师邀请码。
3. 老师用自己的微信进入小程序，选择“我是老师”，填写姓名与教师邀请码。验证后只能访问自己被分配或自己创建的班级。
4. 学生选择“我是学生”，填写姓名、班内编号和班级码，阅读数据说明后提交入班申请。
5. 老师在工作台核对名单，点击“确认”。学生编号在同一个班级内不能重复占用；拒绝申请会释放编号供正确学生使用。
6. 学生背词后，联网同步。老师看到的是真实已同步记录，没有活动时显示空列表或 0。

本机游客记录与班级账号记录分开保存，不会自动混入某个学生的实名记录。退出账号保留该账号未同步队列，重新进入同一账号可继续补传。换设备需要先完成云端同步。

## 4. 全量音频的正式接入

4,524 个录音已全部归档并保留原路径，但没有替你部署到尚未提供的云账号。默认模式为 Unit 1 内置录音，其余单元使用原网站的 HTTPS 地址。若原站不可用、音频迁移或平台域名要求不满足，需切到自己的音频服务；项目没有关闭域名校验。

推荐将 `audio-resources/audio/` 完整上传到与小程序关联的云开发环境，云端路径继续以 `audio/` 开头。可以用云存储控制台上传目录，也可以使用附带脚本批量上传并断点续传。

批量脚本默认只列出计划，不上传文件：

```bash
node tools/upload-audio.cjs --dry-run
```

需要实际上传时，在自己本机安装根目录依赖，使用具有目标环境上传权限的腾讯云凭据。下面是 Windows PowerShell 写法，具体值只在自己的终端填写：

```powershell
npm install
$env:TCB_ENV_ID = "你的云环境ID"
$env:TCB_SECRET_ID = "你的访问凭据ID"
$env:TCB_SECRET_KEY = "你的访问凭据密钥"
node tools/upload-audio.cjs --upload
```

脚本保留本机断点记录 `cloud-audio-upload.local.json`（已加入 Git 忽略），完成后输出实际 `audioCloudRoot`。将这个根地址填入 `miniprogram/config.js`，并确保 `cloudEnv` 为同一个已关联环境：

```js
cloudEnv: '你的云环境ID',
audioCloudRoot: 'cloud://实际环境.实际存储桶',
```

`audioCloudRoot` 必须复制实际文件 ID 中 `/audio/` 之前的部分，不要自行拼写存储桶名。配置后所有录音通过云文件 ID 读取，不依赖 GitHub 音频地址。云存储必须允许目标用户读取课程文件；上传及覆盖只应交由管理端执行，具体规则按实际账号体系设置。

如果使用自己的 HTTPS 音频站，可保留 `audioCloudRoot:''`，把 `audioBaseUrl` 改为自己的站点根目录，保留 `audio/...` 子路径。在微信后台按平台要求配置域名和证书，并用真实手机验证。播放音频仍消耗存储/分发流量，不能把小程序当作无限免费音频托管。

## 5. 通知和复习

教师可以发布自己班级的站内通知；学生进入词书时显示未读弹窗，已读后在通知中心保留。云端读取最近 100 条可见通知，长期运营可再增加分页。站内公告不等于退出小程序后的微信订阅消息，后者需另外接入模板和订阅授权。

无云端服务时，可编辑 `miniprogram/data/notices.js` 中导出的公告数组，字段参考 `docs/公告示例.json`；重新编译发布后生效，本机已读不跨设备同步。

间隔复习按表现调整：认识后逐次延长 1、3、7、14、30、60 天；模糊的词安排短期复习；遗忘的词本轮稍后再次出现，并保留短间隔复习任务。这是可调整规则，不把一次“认识”当作永久掌握。教师看到的自评和听写核对分别记录，点读浏览不自动等同于背词掌握。

## 6. 以后继续同步网站

`tools/import-current-website.py` 接受一个完整的网站 Git 检出目录，以该目录的实际提交为快照，重新生成单元分包、词卡索引和音频资源目录。不要用模型生成内容覆盖文档事实。

```bash
python tools/import-current-website.py /path/to/English-learning
node tools/rebuild-catalog.cjs
node tools/validate-project.cjs
```

Python 转换徽标需要 Pillow。所有课程事实可追溯到 `course-sources/`，单元资源与网站原 JSON 逐字节对应；`audio-resource-manifest.json` 记录全部录音的路径、大小和摘要。换录音必须同时更新字幕时间数据。

旧版 15 词演示工程与当前词书不同。历史学习记录不被当作新词书的已掌握记录；如果曾部署旧版，请先完成原记录同步及备份，再更新线上词表。当前师生框架及云端权限机制保留。

## 7. 验证与上线

开发者可在根目录安装开发依赖并运行：

```bash
npm install
npm test
npm run check
python tools/audit-audio.py
```

音频容器检查需要 ffprobe。检查核对全部 120 个单元、1,800 词条和例句、来源、批注、词卡、字幕及 4,524 个录音文件；还包括播放器、快速切换时序、师生权限和同步去重。

正式上传前，请用真实 AppID 和自己的云环境，分别在安卓和 iPhone 预览，尤其检查首次资源分包、录音读取、0.75×、字幕和跳转；按 `docs/真机验收清单.md` 操作。再完成微信后台资料、上传、提审及发布。工程没有持有你的 AppID 或云凭据，不能宣称已经完成真机验收或微信审核。

`docs/隐私配置说明.md` 中的运营主体、有效联系方式和删除渠道必须补全并与微信后台一致。课程与录音的实际运营使用权由运营者核对。所有部署密钥、个人配置和真实学生数据均不应提交到仓库。

## 目录

- `miniprogram/`：原生小程序、8 个单元资源分包、3 个 Unit 1 录音分包。
- `cloudfunctions/learning/`：师生、班级、通知与学习同步云函数。
- `audio-resources/audio/`：完整录音，供上传自己的云存储。
- `course-sources/`：网站来源文档投影、有道审计、句子录音清单及单元对应表。
- `tools/`：同步、全量校验与云音频上传工具。
- `tests/`：业务与编译检查；`SOURCE.json`、`QA_REPORT.md`：本次快照与验证记录。
