# 海纳教育·英语重点词点读

蓝白简约风格的英语学习网页，顶部提供 Unit 1–Unit 120 下拉菜单。目前已添加 Unit 1，其余项目标记为“待添加”，收到资料后可继续扩展。

页头采用海纳教育蓝黄徽标，图标尺寸为桌面 40px、中屏 36px、手机 32px，并在手机窄屏上完整显示品牌名称。

每个 Unit 按“单词 → 真题例句”排序。Unit 1 包含 15 个重点词和 15 条真题例句，保留原文、音标、词义及中文译文。

页面保留 Unit 标题、朗读速度、单词和真题例句，例句译文始终显示。朗读速度支持 0.5×、0.75×、1.0× 和 1.25×，并记住上次选择。

点击例句中的任意单词可打开词卡，查看音标、词性和中文释义，再点击卡片内的发音按钮听读。点击卡片外、关闭按钮或按 Esc 可关闭词卡。单词区点读、句后小喇叭读整句及分区依次朗读均保留，连续播放和单次播放共用一个播放器，按 Esc 可停止朗读。所有发音使用仓库内的独立英式录音。

Unit 1 的单词区与弹出词卡统一读取有道资料：英式音标、词性、中文释义和英式音频。每种词性最多保留 3 条原文短释义，原条目不足时保留实际数量；按例句需要选择义项，省略普通词中无关的人名义。词卡提供有道来源链接，原形与点击词形不同时显示词头说明。

共查询 200 个词形，188 个取得完整英式资料，15 个重点词均完整。另有 12 个词形缺少有道英式字段：`1988`、`200`、`25,000`、`attended`、`Barcelona`、`densities`、`MWC`、`Nishinari’s`、`quake-resistant`、`starting`、`stresses`、`years`。这些条目仅显示有道实际提供的字段，并标注缺项。数字 `10` 采用有道明确关联的 `ten` 词条，显示实际词头。`striking` 的动词义通过有道明确的原形链接引用 `strike`，音标和音频仍取自 `striking` 自身。

点击句后小喇叭或真题例句的“依次朗读”，会打开字幕式播放层：当前句子居中放大，背景变暗并模糊，已读文字为蓝色，未读文字为白色，每个词内部随朗读进度渐变。暂停、继续和前后跳转时，变色位置跟随音频实际时间更新。依次朗读会在每句结束后自动换到下一句，全部结束后关闭播放层。

句子下方按“后退 5 秒 → 暂停／继续 → 前进 5 秒”排列。桌面端中间按钮为 68px、两侧为 48px；手机端为 60px 和 44px。短句使用较大字号，长句和横屏会缩小字号；超出可用高度时，仅字幕区域滚动，控制按钮保留在下方。左右方向键也可跳转 5 秒，Esc 或关闭按钮会停止播放并返回页面。

网页入口：index.html。原有 vocabulary.html 页面保持独立。
GitHub Pages：https://leefitz19981027-dot.github.io/English-learning/

单词英式音频保存在 `audio/youdao-unit1/`，保留有道返回的原始 MP3 或 WAV 字节，并记录校验和。整句播放使用已有的英式例句录音及对应时间区间。旧版本音频文件保留在版本目录中，当前单词播放使用有道资料指定的本地路径。

扩充 Unit 时在 content.js 的 window.COURSE.lists 中加入对应编号的数据（1–120），保留单词原文、例句、译文及整句音频路径。下拉菜单会自动开放已有资料的 Unit。dictionary.js 保存页面实际使用的词条（小写词形 → `ipa`、`senses: [{pos, meanings}]`、`audio`、`source`、`status`、`missing`），新增例句时需核实所有词形（包括专名、变形和数字）。浏览器使用本地词条及音频，不依赖临时调用有道接口。

`data/youdao-unit1.json` 保存词条缺项、来源 URL、采集时间、原始响应 SHA-256、相关字段投影和音频校验信息。`python3 tools/import_youdao.py --plan` 可枚举查询范围；先用 `--word crucial` 验证实时接口，再按需批量导入。工具通过 HTTPS 从有道获取资料，仅接受明确的英式字段与音频引用，默认把缓存及待审核文件写入 `/tmp/english-learning-youdao/`，不会直接覆盖已发布词典。

本地运行：云环境已有 Python、aiohttp、Node.js、Playwright 和 Chromium。在仓库目录执行 `python3 tools/serve.py --port 8003`，使用支持 HTTP Range 的静态服务验证音频跳转；Python 自带的 `http.server` 不支持字节范围请求，不适合验证快进／后退。其他开发机器需自行安装 aiohttp。线上仍由 GitHub Pages 提供纯静态页面。

保持本地服务运行，在另一终端执行 `node tests/playback.smoke.cjs`。可通过 `TEST_BASE_URL` 和 `CHROMIUM_PATH` 指定服务地址和浏览器路径。该检查使用实际音频，覆盖 15 句的自动切换、字幕变色、暂停、跳转、结束、词卡与 0.5× 回归，以及手机竖屏和横屏布局；截图写入临时目录。

`node tests/youdao.smoke.cjs` 检查全部来源短释义、英式音标、188 个音频的哈希和解码结果，逐个打开 195 个例句词形的词卡，验证缺项显示、英音播放和手机布局。

sentence-timings.js 保存现有 15 句、269 个词元的离线时间区间及音频 SHA-256，浏览器无需语音模型或外部接口。区间由 PocketSphinx 5.1.1 对录音与既有文本进行双遍强制对齐，可能有轻微边界误差。替换录音或例句时应同步更新清单并重跑 `tools/generate_sentence_timings.py`（安装及校验方法见脚本说明）。尚未生成对齐数据的新句子会按发音长度分配播放进度，作为临时回退。
