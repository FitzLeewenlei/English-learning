# 高频重点词·英语点读

蓝白简约风格的英语学习网页，顶部提供 List 1–45 下拉菜单。目前已添加 List 1，其余项目标记为“待添加”，收到资料后可继续扩展。

每个 List 按“单词 → 真题例句”排序。List 1 包含 15 个重点词和 15 条真题例句，保留原文、音标、词义及中文译文。

页面保留 List 标题、朗读速度、单词和真题例句，例句译文始终显示。朗读速度支持 0.5×、0.75×、1.0× 和 1.25×，并记住上次选择。

点击例句中的任意单词可打开词卡，查看音标、词性和中文释义，再点击卡片内的发音按钮听读。点击卡片外、关闭按钮或按 Esc 可关闭词卡。单词区点读、句后小喇叭读整句及分区依次朗读均保留，连续播放和单次播放共用一个播放器，按 Esc 可停止朗读。所有发音使用仓库内的独立英式录音。

网页入口：index.html。原有 vocabulary.html 页面保持独立。
GitHub Pages：https://leefitz19981027-dot.github.io/English-learning/

音频按版本保存在 audio/ 下，逐项绑定原文，避免按显示序号错配；生成流程先裁剪原始音频，再调整语速。新增例句来自上传的句子文档，新增单词音频使用 Sonia（en-GB），原单词和短文及新增整句使用 Melania（en-GB）。

扩充 List 时在 content.js 的 window.COURSE.lists 中加入对应编号的数据，保留单词原文、音标、释义、例句、译文及每项音频路径。下拉菜单会自动开放已有资料的 List。dictionary.js 保存本地词卡资料（小写词形 → ipa、pos、meaning），新增例句时需补齐所有词形（包括专名、变形和数字）及其单词音频。词卡释义对应当前例句的用法，不依赖在线词典接口；日语人名的音标为近似读音。
