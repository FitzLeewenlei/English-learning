# 正式运营前的隐私配置

小程序中的 `pages/privacy/index.wxml` 已说明当前代码采集的主要数据，但尚未绑定实际运营主体。请在正式发布前补齐并确认以下内容。

| 项目 | 需要由运营者填写或决定 |
|---|---|
| 运营主体 | 小程序注册主体的准确名称 |
| 联系渠道 | 能处理更正、转班、解绑及删除请求的邮箱、电话或校区服务渠道 |
| 保存期限 | 学习记录保留多久，离班后何时删除或匿名化 |
| 数据提供对象 | 本班教师及管理员的实际授权范围 |
| 云服务 | 实际使用的微信云开发环境和存储服务 |
| 权限变更 | 教师调班、离职或学生转班时，由管理员及时更新云端关系 |
| 删除流程 | 如何核验本人请求、删除云端及本机记录并反馈处理结果 |

默认代码不会主动取得头像、微信昵称、手机号、定位、通讯录或录音权限。听音拼写使用已有音频播放，不录制学生声音。

当前收集项包括：微信小程序身份衍生的账号编号、主动填写的姓名/学生编号/班级、单词练习时间、记忆反馈、听写结果、通知已读记录。登录加入班级前提供了阅读说明和同意操作；在微信后台仍需按实际功能完成正式“用户隐私保护指引”配置，工程内说明页不能替代平台配置。

本项目没有自动删除账号界面。运营者收到合规删除请求后，可在云端按用户编号核查并删除 `users`、`studentClaims`、`progress`、`studyEvents`、`dailyStats`、`readReceipts` 等关联记录，并在班级管理关系中处理其身份。不要只删 `users` 而留下学习事件。删除操作应先核对请求和依赖关系，并按运营政策处理必要备份。

不要把本文的待填项原样作为正式对外隐私政策。若后续增加跟读录音、手机号、定位或第三方 SDK，需要相应更新告知、授权和平台声明。
