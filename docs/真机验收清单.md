# 真机验收清单

使用自己的真实 AppID，在至少一台安卓、一台 iPhone 上预览。以下是运营前待完成的检查，不代表已经验收通过。

## 本机词书与播放

- Unit 1–120 均能加载；每个单元15个词条和15组例句，来源及词形批注一致。
- 单词区 15 个词依次能播放，单次与顺序播放不重叠。
- 抽查不同单元的例句均能播放；点击英文词形能展开相应释义、音标、词性并听该词发音。
- 第一次加载8个单元资料分包及3个Unit 1音频分包时能正常等待并播放；弱网失败后可以重试。
- 首次分包尚未下载完就关闭播放层，不会稍后自行响起。
- 句子放大、词内变色、暂停与恢复、后退/前进 5 秒、自然结束和顺序切句均正常。
- 检查 0.5×、0.75×、1×、1.25× 在两类手机上是否生效；如具体机型不支持某一档位，在发布版本中调整档位并说明。
- 横屏、窄屏、长句、系统大字体下，关闭和播放控制仍可触达。
- 切换底部导航、退出页面、微信切入后台时，当前播放器停止；接听电话后不会擅自恢复。

## 背词与同步

- 答案初始隐藏，“查看释义”后才可评分。
- “不认识”在本轮稍后出现；“认识”产生下次复习时间。
- 退出再进能保留本机记录；听写大小写和前后空格能正确处理。
- 同一天重复练同一词不会把“今日新学词数”重复增加。
- 断网练习后恢复网络，待同步队列能上传且不会重复计数。
- 同一账号换设备能读取已同步进度；退出账号后不把旧账号记录混给其他账号。

## 师生权限

- 非教师不能通过切换界面、伪造班级 ID 或直接调用云函数查看学生记录。
- 教师邀请码只能使用一次；过期后不能使用。
- 学生提交申请后，在教师确认前不能读本班公告。
- 重复学号被提示核对；老师拒绝错误申请后，正确学生可再次申请。
- A 班老师不能查看 B 班学生或公告；教师详情页与服务端都检查归属。
- 全部集合的客户端读写安全规则已关闭，业务仅经云函数授权。
- 学生练习后，老师看到的日期、今日词数、练习次数和听写结果与记录一致。

## 发布与隐私

- AppID、云环境、云函数依赖、超时时间、数据库索引配置完整。
- 运营主体、联系方式、数据删除渠道和保留规则已填写。
- 微信后台类目、备案、隐私保护指引与实际功能一致。
- 完整音频已上传自己的云存储或可用HTTPS站点，已验证文件权限和真实域名；没有依赖开发工具“不校验域名”选项。
- 云服务套餐、流量预算、错误监控和数据备份由运营者确认。
